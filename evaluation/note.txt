- Mục đích là tạo môi trường Python riêng và cài PyTorch tương thích với GPU A100 cùng driver NVIDIA hiện tại của máy:

1. Tạo thư mục cache để Conda lưu gói tải xuống và thư mục tạm tmp mới (thư mục mặc định ở /home bị hết dung lượng):
mkdir -p /data/lananh/conda-pkgs /data/lananh/conda-envs /data/lananh/tmp /data/lananh/pip-cache /data/lananh/huggingface /data/lananh/.cache/modelscope

Lưu cấu hình cho những lần sau: conda config --prepend pkgs_dirs /data/lananh/conda-pkgs

2. Chuyển cache và thư mục tạm tmp sang nơi bạn có quyền ghi, xử lý lỗi `NoWritablePkgsDirError`
export CONDA_PKGS_DIRS=/data/lananh/conda-pkgs
export TMPDIR=/data/lananh/tmp
export PIP_CACHE_DIR=/data/lananh/pip-cache
export HF_HOME=/data/lananh/huggingface
3. Tạo môi trường riêng tên `asr-mt`, dùng Python 3.10
conda create --prefix /data/lananh/conda-envs/asr-mt python=3.10 -y
4. Chuyển sang dùng Python và thư viện của môi trường mới
conda activate /data/lananh/conda-envs/asr-mt
export MODELSCOPE_CACHE=/data/lananh/.cache/modelscope
export TMPDIR=/data/lananh/tmp
export PIP_CACHE_DIR=/data/lananh/pip-cache
export HF_HOME=/data/lananh/huggingface
5. Cài PyTorch và TorchAudio bản CUDA 12.1 phù hợp với driver hiện có
python -m pip install torch==2.5.1 torchaudio==2.5.1 --index-url https://download.pytorch.org/whl/cu121

- Sau khi cài xong pytorch mới, kiểm tra:
python -c "import sys, torch; print(sys.executable); print(torch.__version__); print('CUDA:', torch.cuda.is_available())"
- Kết quả mong đợi:
/data/lananh/conda-envs/asr-mt/bin/python
2.5.1+cu121
CUDA: True

- Mỗi lần mở terminal mới để chạy project, bạn cần kích hoạt ại: chạy lại bước 4
- Biến cache trên chỉ áp dụng trong terminal hiện tại. Lần sau mở terminal mới, nếu cần cài thêm gói bằng Conda: chạy lại bước 2


- Môi trường Conda vừa tạo đã là môi trường ảo, nên bạn không cần tạo thêm .venv. Ta sẽ cài thư viện trực tiếp vào /data/lananh/conda-envs/asr-mt.

- Cài đặt các thư viện cần thiết:
python -m pip install --upgrade pip
python -m pip install transformers accelerate sentencepiece soundfile sacrebleu tqdm unbabel-comet safetensors
